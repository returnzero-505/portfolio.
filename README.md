A responsive personal portfolio starter for an Electronics and Communication Engineering undergraduate.

- About section
- Projects for a transistor-based NOT gate and a C terminal calculator
- Learning roadmap
- Writing section

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

No build tools or installation are required.

## Publish for free with GitHub Pages
1. Create a GitHub repository, for example `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select your main branch and the `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The Pages settings will show the public URL.
